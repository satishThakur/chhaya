# memory.example

A generic seed, not anyone's memory. Personal memory is data and lives outside this
repository, in `$CHHAYA_GATEWAY_HOME/memory` (default `~/.chhaya/gateway/memory`), as its own
local git repo. `make dev-up` creates it; to start from this seed, copy it in first:

    mkdir -p ~/.chhaya/gateway && cp -r memory.example ~/.chhaya/gateway/memory

This repository is public. Never commit real memory here.
